# Описание программы

Программа написана на языке C# и предназначена для работы с точками на плоскости.
Координаты точки задаются в декартовой системе координат: по оси `X` и по оси `Y`.

## Класс Point

В программе создан класс `Point`. Он описывает одну точку на плоскости.

У класса есть два свойства:

- `X` - координата точки по оси X;
- `Y` - координата точки по оси Y.

Свойства имеют `private set`, поэтому изменить координаты напрямую извне класса нельзя.
Для изменения координат используются специальные методы.

## Конструктор

Конструктор `Point(double x, double y)` создает новую точку и задает ей начальные координаты.

Пример:
Point firstPoint = new Point(3, 4);

В этом примере создается точка с координатами `(3; 4)`.

## Перемещение точки

Метод `MoveX(double distance)` перемещает точку по оси X.

Если значение `distance` положительное, точка перемещается вправо.
Если значение отрицательное, точка перемещается влево.

Метод `MoveY(double distance)` перемещает точку по оси Y.

Если значение `distance` положительное, точка перемещается вверх.
Если значение отрицательное, точка перемещается вниз.

Пример:
firstPoint.MoveX(2);
firstPoint.MoveY(-1);

После этих команд точка переместится на 2 единицы по оси X и на -1 единицу по оси Y.

## Расстояние до начала координат

Метод `DistanceToOrigin()` вычисляет расстояние от точки до начала координат `(0; 0)`.

Используется формула:
sqrt(X^2 + Y^2)

Например, для точки `(3; 4)` расстояние до начала координат равно `5`.

## Расстояние между двумя точками

Метод `DistanceTo(Point other)` вычисляет расстояние между текущей точкой и другой точкой.

Используется формула:
sqrt((x1 - x2)^2 + (y1 - y2)^2)

В программе создаются две точки:
Point firstPoint = new Point(3, 4);
Point secondPoint = new Point(7, 1);

Затем программа выводит расстояние между ними.

## Метод ToString

Метод `ToString()` возвращает координаты точки в удобном виде:

```text
(X; Y)
```

Это позволяет красиво выводить объект `Point` на экран через `Console.WriteLine`.

## Что делает программа

1. Создает две точки.
2. Выводит их координаты.
3. Находит расстояние от первой точки до начала координат.
4. Находит расстояние между двумя точками.
5. Перемещает первую точку по осям X и Y.
6. Выводит новые координаты первой точки.
